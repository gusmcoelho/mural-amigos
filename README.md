# mural de amigos ♡

> um mural interativo pra meus amigos descobrirem suas senhas e mensagens

🔗 **[gusmcoelho.github.io/mural-amigos](https://gusmcoelho.github.io/mural-amigos/)**

cada pessoa tem um link único, uma dica e uma mensagem personalizada só pra ela.

## rodar localmente
```
npm install
npm run dev
```

## deploy
```
npm run deploy
```
